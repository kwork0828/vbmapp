# VB-MAPP 레벨 2 체크리스트

> **상태: 완료 (단일 HTML 파일)**

VB-MAPP(언어행동 마일스톤 평가) **레벨 2(18~30개월)** 마일스톤 60개 항목을
아이별로 체크하고 진행률을 확인하는 웹앱입니다. 서버 없이 `index.html` 한 파일로 동작합니다.

## 기능

- **아이별 프로필**: 이름 + 4자리 PIN으로 프로필 생성·로그인·삭제
- **영역별 체크리스트 (11개 영역)**: 맨드, 택트, 청자 반응, 시지각 기술과 매칭, 독립 놀이, 동작 모방, 음성 모방(Echoic), LRFFC, 인트라버벌, 교실 루틴과 그룹 기술, 언어적 구조
- **진행률 표시**: 영역별·전체 달성 수와 비율
- **자동 저장**: 체크 즉시 브라우저 `localStorage`에 저장

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 설치할 것이 없습니다.

## 주의

- 데이터는 **해당 브라우저에만** 저장됩니다. 다른 기기와 동기화되지 않고, 브라우저 데이터를 지우면 함께 삭제됩니다.
- PIN은 아이별 화면을 구분하기 위한 용도이며 보안 기능이 아닙니다.
- VB-MAPP 문항은 평가 도구의 요약입니다. 실제 평가는 원 매뉴얼과 전문가 판단을 따르세요.
